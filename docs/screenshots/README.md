# Screenshots

Drop three phone screenshots in this folder with these **exact filenames** — the main
`README.md` references them:

| Filename | What to capture |
| --- | --- |
| `lists.png` | The "My Lists" home screen (with a list or two) |
| `list-detail.png` | A list opened, showing a few items (some checked off) |
| `completed.png` | A fully-checked list showing the "All done 🎉" banner / confetti |

Portrait PNGs from your phone are perfect. Once added, commit and push — GitHub will render
them at the top of the README.
